轻续 · Token 工作台 0.9.3
Windows x64 分享预览版

1. 把 ZIP 解压到本机目录，双击「轻续.exe」。程序已带运行环境。
2. 使用过 Codex 桌面端后，轻续可读取当前 Windows 用户的本机聊天、用量日志和配置。采用当前用户的 .codex 目录或已设置的 CODEX_HOME。聊天清单按本机 Codex 侧栏的项目与聊天展示。
3. 在「聊天用量 → 当前聊天」选中聊天。右侧显示最近请求、累计用量、内容来源及诊断。顶部「提醒设置 · 80%」可改比例或暂停。换聊由你决定。
4. 配置建议先用副本。进入「配置与恢复」，选文件并读取，勾选项目，预览后确认「备份并应用」。设置和恢复回执保存在 %LOCALAPPDATA%\Qingxu。
5. 手动交接时，在「交接与知识库」复制保存指令给旧聊天。把它返回的短摘要粘贴到「交接摘要」，然后复制恢复指令，在同项目新聊天发送。

本版从可识别的 Windows Codex 本机记录读取数据。无聊天日志或客户端数据布局不兼容时，用量会提示暂无样本，仍可手动选择配置文件。日期快照采集、自动私有断点和 Obsidian 项目映射属于独立的本机集成，本包提供手动交接。

压缩包内只有程序、使用说明及许可证。各人的本机数据和设置各自保存。应用通过显式确认写配置。消息发送、换聊和知识库更新由使用者自己操作。
