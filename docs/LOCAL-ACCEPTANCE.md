# 轻续 0.10.0-rc2 · Windows 本机验收

当前维护版的增量验证见 [0.10.0-rc4-ui2 本机复验](verification/0.10.0-rc4-ui2/README.md)。下方保留 rc2 完整验收记录。[rc3 本机复验](verification/0.10.0-rc3/README.md)

环境为 Windows 11 x64（22631）、Python 3.14.2、Tcl/Tk 8.6.15。本机显示缩放为 150%。测试记录按 2026-11-10（UTC+8）归档。

| 验收项 | 实测结果 |
| --- | --- |
| 正常启动与两级选择 | 普通入口读取真实 Codex 数据。核对了侧栏项目、指定项目的两条真实聊天、各自工作目录、项目默认选最新聊天和「最近聊天」入口。使用隔离的轻续偏好重复检查，避免覆盖作者偏好。 |
| 旧聊到新聊 | 真正旧聊生成摘要，轻续校验身份、保存并读回。文件引用与携带摘要分别在两个独立新会话恢复正确阶段，并完成首个只读待办。默认 shell 读取受策略限制，完成的两轮仅通过获准的只读工具读取两份合成文件。 |
| 跨项目和聊天 | 用真实日志中的不同会话，切换同项目聊天和两个同名不同路径项目。其他聊天无自动交接，跨项目导入被拒，切换进度与各自日志一致。篡改副本拒绝复用旧凭据，原摘要哈希一致。 |
| 提醒与配置 | 合成回归覆盖阈值、未知、真实零、过期、压缩后待测和暂缓。隔离项目 TOML 预览、备份、写后读回、冲突保护和恢复通过，未勾选字段保持原值。 |
| 运行时采用 | 实际主会话为 `gpt-6.1-sol / low`，实际子会话为 `gpt-6-luna / medium`。Codex 生效配置读到压缩阈值 `48,000` tokens。项目配置已恢复，用户级配置哈希一致。 |
| Windows 界面 | 本机 150% 下观察了窗口与原生选择器。980×680 下以 Tk 96/144 DPI 检查两级选择、三页、接续底栏、悬浮窗四行及收起、展开、隐藏。选择器取消与目录绑定的状态保护由相关回归覆盖。 |
| EXE 与桌面程序 | Windows x64 单文件 EXE 从中文和空格目录解压启动，PATH 无 Python，正常入口读取真实数据。内嵌应用模块及图标与最终源码一致，ZIP 有说明与许可。作者本机原图标启动了原位升级后的 rc2，旧程序已备份，已有数据文件通过哈希核对。 |
| 本地知识 | 在授权的 Obsidian 项目记忆目录创建轻续项目笔记并读回。此动作与应用生成的知识库指令分别记录。 |

## 验证范围

全量回归共 249 项，246 项通过，3 项因本机无文件符号链接权限跳过，0 失败。Windows 目录重解析保护通过真实 junction 测试。100% 结果来自进程内 Tk 缩放，Windows 桌面系统保持 150%。压缩阈值已由 Codex 生效配置回读，达到该阈值后的实际压缩事件仍待验证。任务栏闪动用回调验证，采集器启停和 Token 节省未列为本次通过项。
