# 轻续使用与交接说明

适用版本 0.10.0-rc3。轻续帮助你整理旧聊的任务状态，在同一项目的新聊继续，并查看本机用量。

## 1. 第一次使用

从 [安装包目录](../install/) 下载压缩包，完整解压后打开 `轻续.exe`。在「按项目」中选择本机 Codex 项目，再选择项目下的聊天；也可以切到「最近聊天」。项目列表来自本机 Codex 数据，示例数据会标明，不代表你的真实项目。找不到项目时，可检查设置中的 Codex 数据目录，或使用顶部「手动选择项目目录…」。

打包版的轻续设置默认保存在 `%LOCALAPPDATA%\Qingxu`；源码运行默认使用项目内的 `work/qingxu/data/`。需要隔离测试数据时可设置 `QINGXU_DATA_DIR`。

## 2. 旧聊和新聊怎么接上

1. **给旧聊发指令。** 选好项目和旧聊，打开「会话接续」，点击「复制旧聊指令」。这一步只复制到剪贴板；请由你粘贴发送给所选旧聊。旧聊可以回复摘要，或在有文件权限时保存 Markdown 文件。
2. **接收旧聊摘要。** 把旧聊回复粘贴到摘要框，或读取、导入它保存的 Markdown，检查内容属于当前项目和聊天。直接粘贴的摘要即可用于下一步。
3. **给新聊发指令。** 默认方式会把摘要放进新聊指令。点击「复制新聊指令」，在同一项目的新聊中粘贴发送，再检查新聊是否理解并接续任务。轻续不会自动创建聊天或发送消息。

「保存为 Markdown」会将当前短摘要保存为本地文件，并自动读回核对。文件包含旧聊整理的目标、进度、未完成事项、约束与资料索引，另有项目和聊天标识、时间及内容哈希。导入旧聊文件时会另存一份核验版本。直接粘贴的摘要可跳过保存。选择「读取已保存的 Markdown」时，复制指令前会再次检查文件与项目。

「指定下一阶段目标」默认收起，可以不填。只有想特别告诉新聊接下来先做什么时才需要填写；不填时由新聊根据摘要中的未完成事项继续。

## 3. 项目知识库和模板

知识库是可选的，普通 Markdown 文件夹和 Obsidian 都可以使用。先选好顶部的项目和聊天。在「设置 → 目录与提醒 → 项目知识库」选择类型，浏览并确认当前项目专用的文件夹。接续页的「知识处理与模板（可选）」也可以直达这个设置。请选择项目文件夹；切换到其他项目后需要重新确认绑定。

按需勾选以下分类，保存设置后点击「创建缺失的分类模板」。只为已勾选且尚不存在的文件创建 Markdown 模板，保留已有文件内容。

| 分类 | 文件 |
| --- | --- |
| 目标与需求 | `00-项目概览.md` |
| 计划与步骤 | `01-总体计划.md` |
| 当前进度 | `02-当前进度.md` |
| 决策与阻塞 | `03-关键决策.md` |
| 经验与流程 | `04-工作流与知识.md` |
| 调研与资料 | `05-参考文件索引.md` |
| Bug 与版本 | `06-Bug与版本索引.md` |

勾选项也限定旧聊指令中允许更新的知识文件范围。是否请求更新还取决于所选知识更新方式；轻续生成的是指令，实际更新由旧聊在已有授权范围内执行。请先核对目标目录、项目与分类。

Obsidian 内置模板使用 Markdown 内容，公开的项目管理模板也组织项目、任务和资料。轻续保留上面的七类，不要求安装 Obsidian 插件。[Obsidian 模板说明](https://obsidian.md/help/plugins/templates) · [项目管理模板示例](https://github.com/paquette-dev/obsidian-pm-starter)

## 4. 如何看用量与判断该不该换聊

主页面显示所选聊天，右侧显示最近四条活动。宽度不足时上下排列，可滚动查看。详细记录和 ccusage 日期/项目/主从 Agent 统计保留在次级页签。

进度的分子是日志中的最近请求总量参考，不能与累计用量互换。分母旁边明确标注：本会话报告的运行时压缩线、配置文件参考线、窗口容量或自定义提醒线。配置文件出现某值，不代表当前运行中的会话已经采用。

| 提醒模式 | 这版的行为 |
|---|---|
| 官方参考 | 有可核验的会话运行时压缩线时跟随该线；没有依据显示未知。本轮未接入独立官方默认阈值适配器。 |
| 轻续推荐 | 已知参考压缩线的 80%；只有窗口容量时取窗口的 70%。这是提前收尾规则，不是官方推荐或最优费用保证。 |
| 自定义 | 输入参考容量百分比或固定 Token 数；仅控制轻续提醒，不修改 Codex 自动压缩配置。 |

当用量达到所选提醒线的 90% 时进入提前提醒状态，到达提醒线时建议先保存交接、避免再追加大任务。你可以完成一个较小且明确的收尾动作，再开新聊天。旧测量过期、时间异常、未知数据或读失败不会冒充当前进度或触发错误警报。

发现更新的压缩记录后，旧进度会清空，等待压缩后的新测量。未知显示 `—`；真实零才显示 `0%`；历史值标“上次”。没有可靠的“省了多少费用”基线时，本版不展示虚构节省比例。

## 5. 悬浮窗

从侧栏或用量卡打开小窗，可选“所选聊天”或“最近活跃”。**所选聊天跟随的是轻续顶部选择**，不会识别你在 Codex 桌面刚点击了哪个窗口或标签。

点击小窗某条记录会更改轻续的选择；切换时旧数值清空，再读该聊天。最近活跃按记录时间排序，最多四条。警报优先针对轻续所选聊天；没有选择时才参考最近首条，避免别的项目抢占你的当前流程。

“稍后 10 分钟”只暂缓那条会话的提醒，进度继续更新。“准备交接”进入主窗口的三步流程。“收起”变成约 120×64 的小牌，可拖动、展开或隐藏；“隐藏”不退出轻续。

## 6. Codex 配置与 Agent

在「设置 → Codex 配置」先检查目标配置文件，再选择数值方案。预览会列出实际变更，确认写入前可检查；写入时保留备份，以便恢复。

- **推荐 · 模型默认**：页面显示本机可核实的模型参考值。应用时，勾选的数值项会清除配置文件中的对应覆盖，交由模型默认值决定；参考值不表示轻续会把这些数字写入配置。
- **自定义**：显示文件已有数字并允许修改。切换到此方案时可载入之前记住的数值。勾选要应用的项。勾选后留空表示清除该项覆盖、使用默认值。

先设置 Codex 压缩与输出数值，再设置主 Agent 与子 Agent。轻续自己的提醒阈值在「目录与提醒」单独设置，并不等同于 Codex 的压缩阈值。配置应用后应重新打开 Codex，并用实际运行情况确认它采用了预期设置；配置预览和写入成功本身不能证明运行时已生效。

## 7. 遇到问题

- 列表为空：检查 Codex 数据目录；也可用顶部“手动选择项目目录…”手动接续，无日志时用量保持未知。
- 摘要未读到：核对旧聊天是否真的执行、保存路径是否可读，再使用导入或粘贴方式。
- 切错聊天：未保存编辑有保护；最近交接只自动读取所选源聊天，不偷用同项目另一聊天。
- 配置应用按钮禁用：先读取文件并产生有变化的有效预览；单纯查看不会启用应用。
- ccusage 为空：确认快照文件位置与格式。未连接快照不等于采集器已经停止。
- 启动失败：检查 Python 版本/Tk，并查看轻续偏好目录中的 `logs/startup-error.txt`。
