## 口径与边界

「更多指标」按已知样本汇总新增输入、输出和缓存读取。缓存读取未知时不将其假定为零；未记录的缓存写入可能计入新增输入。缓存写入仅显示已记录值的精确下界，并提示可能缺失。费用是本地价表估算，未与供应商或订阅账单对账；没有逐请求用量记录的历史无法可靠还原。

本轮未在具备符号链接创建权限的 Windows 环境重跑那 5 项，也未重新验证真实 Codex 新聊接续或配置在 Codex 运行时的采用。Figma 在线画布未在本轮更新。
