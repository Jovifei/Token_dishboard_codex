# 计费功能验证 · 0.11.0-billing-rc3

本版本把用量统计主口径改为时间范围，并按截图重做计费页面壳层：今天按小时柱状图，近 7 天/近 30 天按日柱状图，全部范围显示 53 周日用量热力图。所有项目在同一时间范围内合并，供应商和模型只作为辅助筛选。

- 401 项总计

- 0 失败、0 异常
- 5 项跳过，均为符号链接权限不可用

新增覆盖时间汇总字段、小时桶、53 周热力图、四个时间范围、跨项目合并、三类明细页签和窄窗口布局。

## 构建与安装

用 `Build-Windows.cmd <不存在的新目录>` 从 `work/qingxu/launch.pyw` 构建 Windows x64 便携包。构建包解压启动后，页面显示 `用量统计`、`今天` 时间按钮、四项主指标和四项次指标；关闭旧程序后可覆盖现有安装目录。
