2026-11-10 在 Windows 11 x64（22631）、Python 3.14.2 上复验。

| 验收项 | 实测结果 |
| --- | --- |
| Windows 全量回归 | 264 项，261 通过，3 项因文件符号链接创建权限跳过。0 失败，0 异常。目录重解析保护用真实 NTFS junction 测试。 |
| 接续页 | Tk 验证复制状态、粘贴后直接生成新聊指令、可选目标、保存读回、文件改动拒绝、切换聊天的草稿保护及跨项目摘要隔离。 |
| 真实 Codex 接续 | 用只读 Codex CLI 运行合成任务。旧聊按轻续格式返回带来源标记的摘要。轻续在尚未保存时生成携带摘要的指令，随后单独保存并读回校验。独立新聊按指令找回首个待办与验收标记。文件引用指令另做本地校验。 |
| 项目知识模板 | 临时项目目录中验证选择、取消、项目切换、按勾选创建缺失页、并发保护和保留现有文件。旧偏好可读。 |
| 数值配置 | 推荐显示模型参考数字。自定义读入文件现值并接受编辑。合成 TOML 副本覆盖预览、备份、读回、恢复及主/子模型推理档冲突保护。 |
| 窗口与安装包 | 980×680 窗口下检查接续底栏、144 DPI 配置控件及直达知识设置。新 EXE 经 ZIP CRC、PE x64、模块与图标校验。在无 Python 的 PATH 和含中文、空格的解压路径启动后正常关闭。 |
