# 压缩日志计费统计 · 0.11.0-billing-rc4 本机验收

本版基于 0.11.0-billing-rc3 增加 `.jsonl.zst` 读取，保留普通日志、项目/聊天筛选和既有请求去重。窗口中的「同步用量」自动连续处理有预算的批次，并显示进度。

## 已验证

- Windows 11、Python 3.14.2、Tk：隔离合成数据全量回归 **411 项，406 通过、0 失败、0 异常、5 跳过**。跳过均为当前用户无法创建符号链接；日志无 Tk 回调或线程析构异常。[测试回执](windows-tests.json)
- 压缩和普通副本去重、关键字段冲突排除、拼接帧、末行无换行、分批续扫、追加/改写/删除、损坏与截断、长行、取消和正文不进入缓存均有回归；计费窗口使用真实索引器和合成压缩日志验证了多批自动续扫及最终加载。
- 对本机真实 Codex 来源使用隔离索引只读扫描，本次发现的压缩归档均已读取完毕，未发现压缩解码错误。真实项目、聊天和完整索引在 Tk 页面读取及筛选通过。私有日志、聊天名称、请求明细和本机统计数值未上传。[脱敏回执](real-coverage.json)
- Windows x64 便携 EXE 在含中文及空格的路径、无 Python PATH 和隔离数据目录下实际打开计费页，读取合成压缩日志、去重并记录损坏归档；包内解码模块及主要程序模块已与源码核对。[EXE 回执](package-exe-zstd.json) · [包校验](package-static.json)
- 原桌面程序和快捷方式已备份，原位更新后从同一快捷方式启动；原有数据文件哈希不变。已在不覆盖现有缓存的前提下放入只读扫描生成的索引，并在桌面真实计费页观察到同步后的数据。[桌面回执](desktop-verified.json)
- Python 3.12 使用隔离安装的 `backports.zstd` 通过压缩索引回归；Python 3.14 使用标准库 `compression.zstd`。缺少解码器时普通日志仍可用，页面提示压缩日志未纳入。

## 边界与安装

每批最多约 128 MiB 展开数据，压缩文件中断续扫时会从帧头重放至已保存的解压偏移；不会将聊天正文解压到磁盘。损坏或截断的归档不纳入统计并显示提示。

扫描完现有日志也只能统计日志里实际存在的 `token_usage_record`。只有 `token_count` 快照或缺失请求用量的历史不能可靠还原；费用为本地价表估算，未与供应商或订阅账单对账。符号链接权限测试仍需在具备相应权限的环境运行。
