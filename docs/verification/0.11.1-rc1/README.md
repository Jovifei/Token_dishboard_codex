# 独立用量统计 · 0.11.1-rc1 本机验收

左侧导航依次为会话接续、用量概览、用量统计和设置，底部保留悬浮窗入口。用量统计独立于选中的聊天，默认查看全部项目；仍可选择当前项目或聊天。

## 已验证

- Windows 11、Python 3.14.2、Tk 的隔离合成数据回归：**432 项，427 通过、0 失败、0 异常、5 跳过**。跳过项均为本机账户不能创建符号链接；日志未发现 Tk 回调异常。[测试回执](windows-tests.json)
- 今天与滚动近 24 小时按小时显示柱状图，近 7 天与近 30 天按自然日显示柱状图；全部历史使用逐日热力图，超过 53 周分段。三个图表指标为 Tokens、请求和成本，日志保留时间、模型、输入、输出、缓存命中与金额。测试覆盖时间边界、空日、时区、跨年、未计价、排序及图表交互。
- 在 980×680 窗口检查导航和控件可达；另检查高缩放设置、统计页布局和短窗口中的键盘焦点。参考用户截图，以合成数据目视检查独立统计页、柱状图与热力图。
- 本机真实 Codex 来源采用隔离索引只读验证，全部历史的逐日请求数与汇总一致。桌面原程序在真实来源下显示项目、聊天和统计页，侧栏显示今日估算；私有日志、截图和具体费用未提交仓库。[脱敏回执](real-coverage.json) · [桌面回执](desktop-verified.json)
- Windows x64 便携 EXE 在带中文和空格的路径、没有 Python PATH 的环境下启动，并使用隔离合成数据读取 `.jsonl.zst`、去重及提示损坏归档。包内主要程序模块与本次源码核对，ZIP 完整性和哈希已检查。[EXE 回执](package-exe-zstd.json) · [包校验](package-static.json)
- 更新桌面程序前已备份旧程序与原快捷方式；更新完成、启动之前原数据逐项哈希一致。启动之后非缓存用户文件未变，原计费缓存完整性检查通过。

## 边界

金额是本地价格表估算，可能只有部分请求可计价，不等于供应商或订阅账单。没有逐请求用量记录的历史无法可靠还原；损坏或尚未读取的日志会提示范围不完整。符号链接相关测试需要在具备创建权限的 Windows 环境复验。真实新聊接续及配置在 Codex 运行时实际采用不属于本轮重新验证的结果。
