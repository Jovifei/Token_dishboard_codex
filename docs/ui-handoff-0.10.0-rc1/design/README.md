# 轻续界面设计稿

这组 SVG 是依据本次修改后的 Tk 页面整理的**静态向量设计稿，不是运行截图**。稿中的项目、路径、摘要、时间和用量均为演示内容，不能用作运行结果或节省 Token 的证据。

## 文件

| 文件 | 内容 |
|---|---|
| [01-usage.svg](01-usage.svg) | 用量概览、参考容量与提醒线、最近活动、一级与二级动作 |
| [02-handoff.svg](02-handoff.svg) | 三步会话接续、固定主操作栏、旧聊与新聊指令的状态说明 |
| [03-settings.svg](03-settings.svg) | 目录与提醒、可选知识资料，以及独立的 Codex 配置页面内容示意 |
| [04-floating.svg](04-floating.svg) | 所选聊天、最近活跃和收起状态；提醒、暂缓、展开与隐藏 |

SVG 采用文字、矩形、线段和分组，没有内嵌截图、位图或脚本。文字保留为 `<text>`，未转为轮廓，可以在支持 SVG 文本的矢量编辑器中修改。字体顺序为 SF Pro Text、苹方、微软雅黑、Noto Sans CJK SC、系统无衬线字体；缺失字体时会替换，需复核换行。

3. 把按钮、输入框、标签、提示卡建立为组件；三步接续用组件变体表达。
4. 按 [UX-SPEC.md](../../UX-SPEC.md) 添加点击连线与状态，不要把导入的静态图形误标成已经可交互。

## 如何对照实现

设计稿用于说明信息层级和动作关系，部分注释卡、尺寸、配色和状态组合为设计表达，不是对 Tk 的逐像素复刻。实际 Tk 控件外观受 Windows 版本、字体、主题及缩放影响，应以运行截图与本机验收为准。设计稿使用较深的动作蓝 `#0067D9`；当前 Tk 主题主色为 `#007AFF`，仍需按目标显示环境核对对比度。

对应源码为 `workbench.py`、`ui_monitor.py`、`ui_handoff.py` 和 `ui_preferences.py`。交互、状态与能力边界见 [UX-SPEC.md](../../UX-SPEC.md)；实际测试记录和本机验收步骤由主交付文档提供。

本次已检查四个 SVG 的 XML 结构，并用 Inkscape 渲染逐张检查布局与中文显示。此检查只验证设计稿，不代替 Tk、Windows 或 Figma 导入验收。
