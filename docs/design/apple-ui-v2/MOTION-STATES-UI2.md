# UI2 实现状态

| 状态 | 行为 |
|---|---|
| 默认 | 原生 ttk 布局、字体、内边距和焦点尺寸不变 |
| 悬停 | 120ms 颜色提亮，不改变位置和大小 |
| 按下 | 再轻度提亮、flat；不凹陷、不缩放、不下压 |
| 松开 | 原生 ttk 回调只执行一次，随后恢复悬停/默认颜色 |
| 键盘 | Tab 保留原生焦点，空格键保留单次原生激活 |
| 禁用 | 原有文字/背景映射；不触发动作；在途动效停止 |
| 业务切换变体 | 旧动效不覆盖新选中样式 |
| 隐藏/销毁 | 取消定时器；关闭弹窗后释放活动引用 |
| 减少动态效果 | 右键小窗菜单（本次运行）或 QINGXU_REDUCE_MOTION=1；即时换色 |

精简悬浮窗的进度仍来自已有监测口径；增加图案不改变数据算法。未知不是0，过期仍显示“旧”。最小120×64，实际尺寸以字体、项目标签和操作按钮的所需尺寸为准，不固定裁切内容。

这是 Tk 实施规范，不是在线 Figma Motion 导出。原生控件外形仍受平台影响；未新增玻璃材质、弹性缩放、循环呼吸或桌面宠物动画。
