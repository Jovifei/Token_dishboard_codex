轻续 · Token 工作台 0.10.0-rc2
Windows x64 候选版

1. 若此说明位于已构建的 EXE 包中，解压后双击「轻续.exe」。若位于源码包，请从根目录 Start-Qingxu.cmd 启动，需要带 Tk 的 Python 3.11+。
2. 三个页面：用量概览、会话接续、设置。顶部项目/聊天选择全局共用。
3. 第一次使用先在「设置 → 目录与提醒」选择 Codex 数据目录和摘要保存目录。知识库可关闭，普通 Markdown 文件夹与 Obsidian 均可选。
4. 接续：复制给旧会话 → 粘贴/导入它返回的摘要 → 保存并核对 → 复制给同项目新会话。可选择读取文件或携带摘要。工具不自动发送消息或创建 Codex 会话。
5. 悬浮窗可显示轻续所选聊天或最近四条活动，支持暂缓提醒、隐藏与收起小牌；不跟踪 Codex 桌面焦点。
6. 最近请求参考、累计用量、窗口容量、压缩参考线和轻续提醒线分别解释，未知不会显示成零。数据不等同于订阅额度或账单。
7. 主/子模型和 Codex 压缩参数在「设置 → Codex 配置」中读取、勾选、预览、备份并应用。文件读回不代表运行时已采用，需要在本机重开 Codex 核对。
8. EXE 的偏好与配置备份默认在 %LOCALAPPDATA%\Qingxu，可用 QINGXU_DATA_DIR 指定。更换目录不搬移原文件。

本候选版提供源码、合成样本和本机验收清单。Windows 打包产物、真实新聊恢复、配置运行时采用、真实知识库写回和采集器启停需要在目标机器验收。
