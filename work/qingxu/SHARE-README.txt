轻续 · Token 工作台 0.11.0-billing-rc3
Windows x64 候选版

1. 若此说明位于已构建的 EXE 包中，解压后双击「轻续.exe」。若位于源码包，请从根目录 Start-Qingxu.cmd 启动，需要带 Tk 的 Python 3.11+。
2. 三个页面：用量概览、会话接续、设置。顶部项目/聊天选择全局共用。
3. 正常启动会读取本机 Codex 项目和聊天。自定义目录、提醒和可选项目知识库可在「设置 → 目录与提醒」管理。勾选分类后可创建缺失的 Markdown 模板。
4. 接续：复制旧聊指令并发送 → 粘贴摘要或导入它生成的文件 → 复制新聊指令并发送。默认携带摘要；需要以后读回或使用文件引用时，可保存为 Markdown。下一阶段目标按需填写。
5. 悬浮窗可显示轻续所选聊天或最近四条活动。收起后显示图标、进度和项目提示。右键可查看完整信息或减少本次运行的动效。
6. 最近请求参考、累计用量、窗口容量、压缩参考线和轻续提醒线分别解释，未知不会显示成零。数据不等同于订阅额度或账单。
7. 在「设置 → Codex 配置」确认文件后先选数值方案，再看压缩与输出、主与子 Agent。勾选要改的值，预览后备份并应用。运行时参数需重开 Codex 核对。
8. EXE 的偏好与配置备份默认在 %LOCALAPPDATA%\Qingxu，可用 QINGXU_DATA_DIR 指定。更换目录不搬移原文件。

项目与使用指南见 https://github.com/Jovifei/Token_dishboard_codex 。

9. 新增“用量概览 → 计费统计”。先同步逐请求记录，再按日期、供应商、模型或当前项目/会话筛选；单价可配置，导出当前范围全部 CSV。金额为当前价表 Token 估算或来源报告金额（未对账），不是订阅账单。无单价、无逐请求记录或无耗时均显示未知，不填假零。
10. 源码根目录 Preview-Billing.cmd 可运行 84 条合成数据演示；不可当作自己的实际消费。用量统计按今天、近 7 天、近 30 天、全部四个时间范围合并所有项目。Windows x64 便携包由 0.11.0-billing-rc3 源码构建。
