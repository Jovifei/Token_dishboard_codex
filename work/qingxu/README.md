# 轻续 · Token 工作台

Windows 本地预览版 0.9.3。便携版解压后双击「轻续.exe」。从源码启动时，在仓库根目录用带 Tk 的
Python 3.11 或更高版本运行 `py -3 -B .\work\qingxu\launch.pyw`。合成演示见 [仓库首页](../../README.md)。

## 交接与知识库

选项目时默认打开最近活动的聊天。可以换同项目的历史聊天，或直接用「最近聊天」查找。轻续记住实际选中的聊天。
项目名称和排序来自 Codex 侧栏。身份或工作目录没有精确匹配时，支持粘贴短摘要接力。

1. 点「复制保存指令」。指令详情立即显示并可编辑。改过后点「复制当前指令」，发给旧聊天。
2. 等旧聊天生成并保存任务摘要后，点「核对交接摘要」读回。收到文字摘要时也可直接粘贴在这里。
3. 点「复制恢复指令」，粘贴到同项目的新聊天。新聊天先核对工作目录、代码与未完成事项。

私有短断点是旧聊天生成的本机短摘要。它包含目标、进展、证据与下一步，最大 8192 UTF-8 字节。
工作目录取自所选聊天。轻续按精确项目登记定位本机 AgentState，知识库页使用独立映射。
指令区的编辑只影响复制的文本。旧聊天接到指令后生成摘要，读回与真实新聊天恢复各有验收。

项目知识库在同一页。勾选目标与需求、计划与步骤等分类，再选「单独生成」或「附到旧聊交接」。
附加时先生成旧聊保存指令。点「生成知识库指令」后核对或编辑，再点「复制当前指令」发给 Codex。
指令按勾选项目和范围处理，映射不明确、缺页新建未获许可或版本冲突时先询问。
「当前进度」留到阶段验收后，决策页只写重要决定或长期阻塞。

## 配置

三个方案为「官方默认（继承）」「轻续推荐（继承数值）」「用户自定义」。官方方案可清除所选字段的
顶层覆盖。推荐方案仅让三个数值继承模型和客户端，同时保留已有推理档、压缩提示和子 agent 设置。自定义方案
可输入整数或「继承」，按准确型号保存到工作台，以便下次选择。应用只改表单选定的文件，
配置档、项目配置、提供商和启动参数也可能参与实际加载。

| 本机 Codex 0.167.0 目录示例 | 默认窗口 | 按默认窗口计算的压缩阈值 | 工具输出上限 |
| --- | ---: | ---: | ---: |
| Astra | 272,000 tokens | 244,800 tokens | 10,000 tokens |
| GPT‑6.1 Sol | 500,000 tokens | 450,000 tokens | 10,000 tokens |
| GPT‑6.1 Terra | 500,000 tokens | 450,000 tokens | 10,000 tokens |

窗口 `model_context_window` 是容量。压缩阈值 `model_auto_compact_token_limit` 决定何时整理较早的聊天历史。
`tool_output_token_limit` 限制单次工具输出保留进上下文的量。1k 等于 1,000 tokens。
工作台会同时显示所选型号的默认参考和配置文件原值。保留窗口覆盖时，实际继承的阈值可能不同。

建议先以表中的继承值作为基线。对于 Sol 或 Terra 的长聊天，如果实际记录显示旧历史反复占用输入，
可仅将自动压缩线试调到 350,000 tokens，比较缓存与非缓存输入、推理输出、压缩次数和返工，再决定是否保留。
先保留 10,000 tokens 的工具上限，并让命令从源头只输出需要的片段。模型目录没有提供所有任务的最佳阈值。
[Codex 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference) · [ACON](https://arxiv.org/abs/2510.00615)

第一次先选择配置副本。点「读取配置」，选方案并核对勾选字段，依次点「预览勾选的修改」和「备份并应用」，
再在确认框检查文件路径。底部固定显示预览、应用、恢复和操作状态。写后读回卡显示目标与实际值。
「主模型高级参数」可展开推理档位和压缩提示。「子 agent 默认设置」可以选模型、填写可用模型 ID，
或选择继承。档位按本机目录显示。Astra、6.1 Sol 和 6.1 Terra 在本机目录列出 Low、Medium、
High、Extra High、Max、Ultra。Luna 到 Max。日常从 Medium 起步，窄范围子任务可从 Low 开始，
复杂单项任务再升档。Ultra 可主动委派，取决于客户端、模型和账号的可用性。勾选后通过同一套预览、备份、应用和恢复流程。
子 agent 默认设置只影响使用该配置的后续派发，显式派发或角色设置可能覆盖。
[OpenAI 模型说明](https://learn.chatgpt.com/docs/models) · [子 agent 配置](https://learn.chatgpt.com/docs/agent-configuration/subagents)

多行 `compact_prompt` 为避免破坏文件会拒绝自动覆盖；请保留原设置，
或独立人工审查。其他未选字段、模型、MCP、权限和 hooks 不修改。
应用或恢复后，在旧聊天保存交接。桌面端完全退出并重开 Codex，再开同项目新聊天验证。
CLI 退出后重新启动即可。配置页显示文件读回值，运行时采用需要单独核实。

「从持久化备份恢复」可跨工具重启恢复；目标有后续修改会拒绝覆盖。
完整原配置备份可能含凭据，不上传、不分享 `data`。
Windows 私有目录限制为当前用户、SYSTEM 和 Administrators；不防本机管理员。

## 用量与采集

「聊天用量 → 当前聊天」按 Codex 侧栏顺序展示项目与活跃聊天。点项目默认选最新聊天，手动可换历史聊天。
右侧同页依次为「最近请求上下文」「聊天累计用量」「内容来源」。三块一起更新，左侧项目树保持可见。
最近请求用量和日志窗口容量用于估算占用。系统工具、消息、系统提示、MCP、技能、压缩预留等无单独分项。
累计用量汇总该聊天可读日志中的独立请求，跳过重复响应，不累加继承的总计。无逐请求字段的旧记录显示无明细。
每 15 秒读取所选聊天的新记录，逐请求累计增量读取，手动刷新可重新核对。占用百分比以日志窗口为分母，
累计构成百分比以该聊天的已计量用量为分母。
「内容来源」单列本聊天最近日志段内的对话消息、系统与开发者消息、可识别的 MCP 调用和其他工具记录。
统计上限为日志尾部 8 MiB 的完整记录。字节包含序列化与图像编码，百分比按表内日志字节计算。
结果的调用记录不在样本里时，显示为「未关联」。

「内容来源」下的「本次诊断」随所选聊天刷新。上下文行显示最近请求的 tokens、参考来源、占用和提醒比例。
工具与 MCP 分别统计日志最近一次活动前 10 分钟内的可识别调用，有调用 ID 时去重，单个工具达到 10 次时提示。
最大结果从上方同一批完整日志记录中选出，显示工具、时间和日志字节，达到 65,536 字节时给出缩减建议。
调用频率和结果体积使用本地排查线，单位分别是调用次数和日志字节。

窗口打开时每 15 秒查询所选聊天的近期用量。顶部「提醒设置 · 80%」可暂停提醒或设为 1–100% 的整数，
偏好保存在轻续私有目录。当前聊天到所设比例，或出现新的压缩记录时，
顶部提示并闪动任务栏一次。界面标明用的是日志运行时阈值、配置文件参考线还是日志窗口。15 分钟以外的
历史样本保留查看，任务栏提醒只针对近期数据。换聊仍由用户触发。

「日期快照」复用 ccusage 的本机增量快照。先看全局，再把鼠标放在圆环上看项目、占比和用量。
点色块展开项目，选聊天标题看该聊天的构成，点「回到总览」清除筛选。灰色项目扇区是未分类，
展开可查聊天和未归类原因。独立构成图的蓝、绿、橙、红依次表示非缓存输入、缓存读取、缓存创建、输出。
主 / 子 agent 有独立表格。当前快照可提供上述构成，轮次、工具输出和截图没有精确 token 归因。
RTK 与 QMD 仍是外部选项。

「刷新用量快照」只读现有增量统计和心跳。缓存输入与非缓存输入分开，
reasoning 是输出子集，不重复相加。不是订阅账单，也不是即时扣费。
心跳新鲜不等于进程身份已验证。

采集器属于可选的本机集成。安装和运行边界见 [冻结版运行说明](../../docs/ui-handoff-0.9.3/RUN.md#可选集成)。
启动前先核对 STOP 原因和是否已有匹配进程。

截图建议：优先 UI 树；必要时裁剪，长边不超过 1280px，JPEG/WebP 不超过 2MB。
本工具没有拦截其他 agent 的截图。阶段结束保存断点后换新聊天。

## 验收边界

安装可用、脚本测试通过和样例知识页写入，都不能替代：
真实空白新聊天恢复、真实项目知识库验收、所有映射项目分批覆盖、
运行时配置采用、可比任务的输入/缓存/输出/质量/返工对照。
没有可靠对照不报告节省百分比；P2 未因此全部完成，不进入 P3/P4。

## 文件与卸载

便携版的偏好、备份和日志默认保存在 `%LOCALAPPDATA%\Qingxu`，源码版保存在 `work/qingxu/data`。
移除应用前先单独保留备份和回执。若应用过配置或知识页，按回执决定是否恢复。
可选的私有断点、项目登记表和知识库由各自的本机路径管理。
