# 轻续 Qingxu 0.10.0-rc3 · Windows x64 安装包

[直接下载 0.10.0-rc3 Windows x64 便携 ZIP](https://github.com/Jovifei/Token_dishboard_codex/raw/refs/heads/main/install/Qingxu-0.10.0-rc3-Windows-x64.zip)

下载后完整解压，双击 `轻续.exe` 即可使用。程序自带 Python 和 Tk 运行环境。正常启动会读取本机 Codex 项目与聊天标题。选择项目后可切换聊天，并查看各自的工作目录。

先保留原版本目录和原数据。Codex 使用自定义数据位置时，到「设置 → 目录与提醒」核对路径。普通启动可直接用真实数据，源码演示窗口会标为「合成演示」。
