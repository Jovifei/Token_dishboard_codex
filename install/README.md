# 轻续 Qingxu 0.11.3-rc1 · Windows x64 安装包

[下载 0.11.3-rc1 Windows x64 便携 ZIP](Qingxu-0.11.3-rc1-Windows-x64.zip)

下载后完整解压，双击 `轻续.exe` 即可使用。程序自带运行环境。打开「用量统计」可使用日历、时分筛选和趋势图，下方显示请求日志。正常启动会读取本机 Codex 项目与聊天标题。

先保留原版本目录和原数据。Codex 使用自定义数据位置时，到「设置 → 目录与提醒」核对路径。普通启动可直接用真实数据，源码演示窗口会标为「合成演示」。费用统计首次同步前请核对单价和数据来源。
